# Box Nº

Приложение для переезда: коробка = номер маркером, фото вещей с AI-подписями, направления, семья.

- `backend/` — Supabase: миграции, политики (RLS), Edge Functions
- `ios/` — iOS (Swift, SwiftUI)
- `android/` — Android (Kotlin, Compose) — позже
- `web/` — boxnumber.co и страницы посылок — позже
- `docs/` — архитектура, схема базы, ТЗ по разделам

Первый этап — раздел «Переезд». Хранение и Посылки в интерфейсе есть, но неактивны.
