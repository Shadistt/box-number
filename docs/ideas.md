# Идеи на потом

Не входят в первый этап. Записываем, чтобы не потерять.

- **eBay** — публиковать вещь на продажу прямо из приложения: фото и подпись уже есть, кнопка «Продать на eBay» → черновик объявления в аккаунте пользователя (eBay Sell API). Также пригодится для Хранения («что лежит и не нужно»). Добавлено 30.10.2026.
- **Распознавание почерка** — проверка номера, написанного маркером (экраны-макеты есть).
- **Авторежим камеры [A]** — штатив, границы коробки, автосъёмка (экраны есть, место кнопки не решено).
- **Облачное уточнение подписей (VLM)** — отдельным шагом после личных эталонов (§11а).
- **Тарифы / подписка** — раздел переосмысливается; карточка в настройках закомментирована до нового решения (30.10.2026).
- **Темы для доступности** (идея 31.10.2026). Лучшая практика Apple — не плодить свои темы, а уважать системные настройки доступности, которые пользователь уже включил: «Увеличить контраст» (`colorSchemeContrast`), «Уменьшить прозрачность» (убрать матовое стекло), «Жирный текст» и Dynamic Type (размер шрифта), «Различать без цвета» (статусы не только цветом — у нас «запаковано» = оранжевый + замок, это уже ок), «Уменьшить движение» (без прыжков коробки). Для дальтоников отдельные палитры мало помогают — важнее иконки и подписи рядом с цветом. Что сделать: 1) высококонтрастный вариант палитры, включается сам при «Увеличить контраст»; 2) все тексты на Dynamic Type; 3) проверка контрастов WCAG AA в обеих темах. Возможная «своя» тема сверх этого — «Крупный шрифт и крупные плитки» для слабовидящих.
- **Токены в тарифах** (идея 31.10.2026, пока не делаем). Действия стоят токены (например, распознавание вещи); токены можно купить или заработать: отправил контактам информацию о Box Nº — условно 10 000, отзыв в Google — 1 000, пост в Instagram/X — 1 000 и т. д. В подписках Бесплатно / Про / Макс — включённое количество токенов в месяц. Связано с переосмыслением тарифов; учесть правила App Store про вознаграждение за отзывы (Apple запрещает поощрять отзывы в App Store; отзывы в Google/соцсети — отдельно проверить).
