# Box Nº · iOS

SwiftUI · iOS 17+ · Supabase Swift SDK. Язык Swift 5 (строгая проверка конкурентности — позже, когда соберём первый раз).

## Как собрать

1. Xcode 16+, Mac. `brew install xcodegen`.
2. В папке `ios/`: `xcodegen generate` → откроется `BoxNo.xcodeproj`.
3. Модель подписей `BoxNo/ML/SigLIP2Image.mlpackage` (67 МБ) лежит в репозитории; без неё приложение тоже соберётся и будет использовать встроенную Vision.
4. Xcode подтянет пакет `supabase-swift`. Signing — автоматический, Team `2P3PUF975G`, Bundle ID `co.boxnumber.app`.
4. Запуск на iPhone: выбрать устройство, ⌘R.

Проект `.xcodeproj` в git не хранится — генерируется из `project.yml`.

## Что уже есть

- Вход: Apple, Google (OAuth через Supabase), email + пароль, подтверждение кодом, забыли пароль.
- Главный: Переезды (Хранение и Посылки неактивны), карточки переездов, пустое состояние.
- Новый переезд: Откуда, Куда 1…5 с перетаскиванием.
- Места переезда: шапка, поиск, Места / Все вещи, фильтры по типу, плитки, FAB → Тип места (8 карточек, свой вариант).
- Экран места: 3D-коробка (клапаны закрываются при запаковке), название, плашка статуса (вариант B: «Едет в …», чипы направлений, кнопка-замок), Фото / Список, живая плитка камеры, вещи.
- Камера на весь экран: снимаем подряд, AI-подпись на устройстве (Vision), «Отменить» тостом.
- Вещь: карточка с подписью, переложить, удалить; при распаковке — «Достал(а)» / «Вернуть».
- Меню «…»: изменить номер и тип, «Куда едет» (с добавлением направления, лимит 5), удалить.
- Фото: сжатие 1 600 px + превью 320 px, локальные файлы, загрузка в R2 через Edge Functions `photo-upload-url` / `photo-view-url`. Пока в Supabase не заданы секреты R2 — фото остаются только на устройстве.

## TestFlight

Каждый push в `main`, который меняет `ios/`, собирает архив на GitHub Actions и отправляет его в TestFlight (`.github/workflows/ios-testflight.yml`). Номер сборки = номер запуска.

Нужны секреты репозитория (Settings → Secrets and variables → Actions):
- `ASC_KEY_ID` — Key ID ключа App Store Connect API
- `ASC_ISSUER_ID` — Issuer ID
- `ASC_KEY_P8` — содержимое файла `AuthKey_XXXX.p8`

Подпись автоматическая: сертификат распространения и профиль Xcode создаёт сам через API-ключ.
